# progress-reporting

让 AI 编码代理**边做边报进度**，而不是埋头连调几十个工具、最后只甩一份结果。

这是一份纯指令型 skill（无脚本、无依赖、无网络访问），规定代理在长任务中：

- 把工作切成带编号的子任务（`第 k/N 项`），与 todo 清单同步；
- 每项开始、每项结束、单步中途、遇阻、需决策、交付前，各给一次播报；
- **中途才变大也补**：发现任务比预估大时，当场说明、回溯已完成项、补全清单，再从当前项按 `第 k/N 项` 继续，不硬撑到结束；
- 每条播报含四要素：位置、带证据的进展、下一步、风险或待确认；
- 状态分层用词：`已完成并验证` / `已完成待验证` / `失败，改用方案 B`，禁止把“跑过命令”说成“验证通过”。

## 效果对照

坏（沉默执行）：

> 好的，我先看一下数据，然后进行分析。（随后十几条工具调用没有任何文字）

好：

> 第 2/4 项：核对两表共有人员金额差异
> - 已按身份证号匹配 128 人，其中 9 人合计差额超 1000 元
> - 下一步：逐人比对专项经费明细，定位差额来源
> - 需确认：手工清单有 3 条重复记录，按去重后处理是否可以

## 安装

技能就是一个目录，里面放 `SKILL.md`；把整个目录复制到对应代理的技能目录即可。

```bash
# DeepSeek Harness（DSH）
mkdir -p ~/.agents/skills && cp -R progress-reporting ~/.agents/skills/

# OpenAI Codex
mkdir -p ~/.codex/skills && cp -R progress-reporting ~/.codex/skills/

# Claude Code
mkdir -p ~/.claude/skills && cp -R progress-reporting ~/.claude/skills/
```

装好后新开的会话即可按 `description` 自动加载；也可以在提问时直接点名，例如“用 progress-reporting 的方式做，边做边报进度”。

## 说明

- 它是**按需加载**的，不是常驻规则。想做到每轮必报，需要在代理的预设 / 系统提示层再落一条常驻指令。
- 技能内容不含任何本机路径、凭据或个人信息，可安全分享。
